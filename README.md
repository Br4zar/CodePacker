
# 📦 Code Packer

> Настольное приложение для Windows, которое собирает исходный код
> проекта из множества файлов в единый структурированный документ.

---

## 🎯 Назначение

Современные проекты состоят из десятков и сотен файлов. При передаче
кода преподавателю, коллеге или системе искусственного интеллекта
приходится вручную отбирать нужные файлы и объединять их содержимое.

**Code Packer** автоматизирует этот процесс:
выберите папку проекта — получите готовый пакет в один клик.

## ✨ Возможности

### 📁 Работа с файлами
- Открытие папки проекта или Drag & Drop
- Отображение структуры в виде дерева
- Выбор отдельных файлов и каталогов
- Поиск по дереву проекта
- Поддержка изображений (PNG, JPG, GIF, WebP)

### 🚫 Фильтрация
- Автоматическое исключение `bin`, `obj`, `.vs`, `.git`, `node_modules`
- Пользовательские расширения файлов
- Пользовательские правила исключения

### ✂️ Оптимизация
- Удаление лишних пробелов и пустых строк
- Удаление однострочных комментариев
- Умная минификация JSON
- Подсчёт размера исходного и обработанного пакета

### 🧮 Оценка токенов
- Приблизительный подсчёт токенов для LLM
- Визуальный индикатор заполнения контекстного окна
- Пресеты: Claude 200k, GPT-4o 128k, Gemini 1.5 Pro 1M, DeepSeek V3 64k, Local LLM 32k
- Подсказки по оптимизации пакета

### 📤 Экспорт
- Копирование в буфер обмена
- Экспорт в TXT
- Экспорт в PDF с настраиваемым размером шрифта

### ⚡ Удобство
- 6 слотов для закрепления часто используемых проектов
- История последних проектов
- Работа через системный трей

## 🚀 Запуск

### Требования
- Windows 10 / 11
- .NET 8.0 Runtime

### Сборка из исходников


git clone https://github.com/ВАШ_ЛОГИН/CodePacker.git
cd CodePacker
dotnet build
dotnet run --project "Code Packer"


Или открыть `Code Packer.sln` в Visual Studio 2022 и нажать F5.

---

## 📖 Использование

1. Запустите **Code Packer**
2. Нажмите **«Открыть папку»** или перетащите папку проекта в окно
3. В дереве файлов отметьте нужные файлы
4. При необходимости настройте параметры оптимизации
5. Нажмите **«Копировать»** или **«Экспорт»**

### Быстрые слоты
Закрепите часто используемые проекты в слоты 1–6
для мгновенного открытия.

### Системный трей
Приложение сворачивается в трей.
Двойной клик по иконке — открыть окно.
